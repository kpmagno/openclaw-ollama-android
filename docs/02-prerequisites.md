# Prerequisites

## Hardware

- Android phone with at least 8 GB RAM recommended
- At least 12 GB free storage

## Software

- Termux (F-Droid build recommended)
- Termux:Boot (for boot scripts)
- Optional: Termux:API

## Network assumptions

- Required for initial downloads (packages, model pulls)
- Local inference can run without internet after setup
- Telegram channel mode still needs Telegram network connectivity

## Skill level

- Comfortable with Linux shell commands
- Comfortable editing text files in terminal

## Security assumptions

- You will use SSH keys for remote access
- You will not commit secrets to Git
